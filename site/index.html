SO-101 HumanGen Pairs

Real robot episodes paired with generated human demonstrations of the same task

[Dataset] [Code]

Overview.

Each pair joins a real SO-101 robot episode with a short generated video of a person doing the same task in the same scene. The robot is removed from its first and last frames, and a video model fills in the hand in between. Two independent reviewers checked every pair for task adherence and physical plausibility, and only pairs that both accepted are kept.

Pairs.

How pairs were selected.

Every accepted robot episode has one generated demo. For each task, candidates were drawn from across the episodes and reviewed in rounds until the task had 10 good pairs. First, a judge looked at the frames of both videos: same steps, same objects, same end state, objects moving only when touched, one acting hand, and no new objects or overlays. Then a second reviewer, asked to find a reason to reject, re-checked every accept frame by frame.

Videos stream from the Hugging Face bucket. The robot views are the original recordings; the human videos are generated.
